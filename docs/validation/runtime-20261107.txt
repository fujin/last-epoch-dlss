FALLBACK-LIMITER LIMITATION

This NVIDIA DLSSG path uses native Reflex. Source review found that DLSSG sets
low-latency Reflex mode and the FG hook skips the fallback sleep when Reflex is
handling the limit. No supported configuration switch was identified that
reliably exercises the changed fallback limiter while retaining this path.

A successful D1B smoke test can establish bounded compatibility of the rebuilt
backend with this installation. It cannot establish that the fallback multiplier
fix executed, improved pacing or reduced NR latency. Direct runtime proof still
requires explicit diagnostic instrumentation or a naturally eligible path.
The candidate's existing pure-policy and full-build checks remain separate.
