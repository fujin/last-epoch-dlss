API COMPATIBILITY REVIEW

OptiScaler advertises Streamline host SDK 2.11.1 in sl_version.h and passes its
encoded kSDKVersion to slInit. Its DLSSG, Reflex, PCL and core API headers match
the official 2.14.1 headers after line-ending normalization. Official Streamline
accepts a valid encoded host version and uses versioned structures. Reviewed core
header differences add newer IDs and split an existing reserved 32-bit field;
the changed UIAlpha enum is unused by this backend. No relevant ABI mismatch was
found for this D3D11-to-D3D12 SR/FG path. The adapter's frame/diagnostic ABI sizes
are also checked at startup. These are coherent API expectations, not a blanket
compatibility guarantee for every game feature or future update.
